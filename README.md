I build software that does the heavy lifting while staying out of your way. Less interested in bloated SaaS subscriptions or 50-step onboarding flows, more into tidy, lightweight tools that compile, run locally, and just work.

Raw dogging native browser APIs, full-stack monoliths, local reverse proxies, and headless scrapers so you don't have to install 400 questionable npm dependencies. Strictly zero telemetry because your data is none of my business.

### What I've Been Cooking

#### Public Systems
- **[session-swap](https://github.com/somaylab/session-swap)**  
  Universal multi-account session switcher and cookie manager for Chrome and Firefox (Manifest V3). Handles 1:1 disaster recovery snapshots, CHIPS `partitionKey` isolation (RFC 6265bis), and offline local persistence without logging you out.

- **[map-scrape](https://github.com/somaylab/map-scrape)**  
  Desktop scraper for Google Maps business entities built with FastAPI and pywebview. Bypasses rate-limiting hurdles in stealth mode and spits out clean, normalized spreadsheets (XLSX/CSV) instantly.

- **[ghost-profile](https://github.com/somaylab/ghost-profile)**  
  Browser anti-fingerprinting extension for Chrome & Firefox. Spoofs WebGL shaders, Canvas 2D noise, AudioContext jitter, hardware concurrency, and locale attributes to keep tracking scripts guessing.

- **[Haha-Cookies](https://github.com/somaylab/Haha-Cookies)**  
  Lightweight session state and tab inspector utility for Chrome MV3. Real-time cookie jar lifecycle telemetry and developer diagnostics.

#### Under the Hood & Private Tooling
- **Juragan-Airport** *(PHP / Laravel 11, Inertia.js, React & Tailwind CSS)*  
  Full-stack enterprise airport handling operations monolith across production, staging, and development environments. Engineered with a Laravel REST API (reservations, invoices, dispatchers) and interactive client portal.

- **Antigravity-Proxy & AG-Standalone-Proxy-Manager** *(Rust & Tauri v2)*  
  Dual-engine local reverse proxies and multi-account routing toolkits with adaptive quota management and zero socket latency overhead.

- **worker** *(TypeScript & Cloudflare Workers)*  
  Retro Macintosh-styled cloud asset downloader and edge stream worker running on Cloudflare's serverless edge.

- **changer-id** *(Java & Xposed)*  
  Low-level device identity spoofer built as an Xposed module for Android 16. Virtualizes hardware identifiers, IMEI, and MAC addresses at the OS framework level.
